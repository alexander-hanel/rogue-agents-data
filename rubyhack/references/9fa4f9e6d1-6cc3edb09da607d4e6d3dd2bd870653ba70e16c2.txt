block users registering with anonymous mail providers (#6510)
* block users registering with blocked email domains

* harden disposable email domain block + add allowlist

Addresses review feedback on the previous commit:

Sync job (app/jobs/sync_disposable_email_domains_job.rb)
- Explicit Net::HTTP.start with TLS VERIFY_PEER, open/read timeouts, and
  bounded redirect follow (was: Net::HTTP.get_response, no timeouts, no
  redirect handling).
- Reject syncs outside [MIN_EXPECTED_DOMAINS, MAX_EXPECTED_DOMAINS] and abort
  when any PROTECTED_PROVIDERS entry appears upstream, so a poisoned or empty
  upstream cannot wipe the table or lock everyone out.
- Filter incoming domains through BlockedEmailDomain::DOMAIN_FORMAT so
  malformed lines never bypass model invariants via upsert_all.
- Replace `where.not(domain: huge_array).delete_all` with a synced_at
  watermark to avoid a 5k-element NOT IN.
- Use on_duplicate: "updated_at = EXCLUDED.updated_at" so admin-promoted
  manual rows aren't reset to upstream each night.

Avo / policy
- Hide `source` field on new; model defaults new records to :manual so admins
  cannot accidentally create source: :upstream rows.
- Document the act_on? per-record-guard requirement for future bulk actions.

Allowlist
- New email_domain_allowlists table + EmailDomainAllowlist model.
- BlockedEmailDomain.blocks?/match consult the allowlist first, so ops can
  exempt legitimate forwarding services (e.g. privaterelay.appleid.com)
  without the next sync re-adding them.
- Avo resource + policy mirroring BlockedEmailDomain.

Observability
- Validator emits StatsD.increment("email_domain.blocked", tags: { source: }).
- Low-cardinality source tag (upstream/manual) lets us measure block volume
  and false-positive impact in Datadog.

Other
- Bump migration Rails version 7.1 -> 8.0 to match neighboring 2026 migrations.

* address review feedback on blocked email domains

* drop the dead upstream allowlist fetch (file no longer exists upstream)
  and simplify line parsing
* default new BlockedEmailDomain records to :manual instead of relying on
  an after_initialize callback that never fired, so Avo-created rows
  survive the daily sync cleanup
* enforce HTTPS on every URL fetched by the sync job, including redirect
  targets, so a Location-header downgrade cannot bypass VERIFY_PEER
* cover the MAX_EXPECTED_DOMAINS tripwire with a test

* add concurrency to goodjob task and retry on common errors

* add avo actions to block domains and create allowed domains

* transition to faraday

* remove Arel.sql usage

* Let ActiveModel handle I18n

* Don't allow (g)TLDs to be blocked

* fill locales

* harden disposable email sync against upstream poisoning

* fixup linting

* cover unblock guard, http error tagging, and first-sync delta bypass
